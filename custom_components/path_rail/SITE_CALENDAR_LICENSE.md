# Holiday calendar attribution

The generated factual US holiday interval table in `site_calendar.py` was produced
using **date-holidays 3.38.0** by **commenthol and contributors**, with country `US`
and default holiday types. The inspected PATH site's JavaScript also creates a US
date-holidays calendar. The package version embedded by that site is not established;
the generated calendar is a documented approximation of that behavior.

Source: https://github.com/commenthol/date-holidays
Data license: https://creativecommons.org/licenses/by/3.0/
Package licensing: ISC AND CC-BY-3.0.

The data was transformed into UTC start/end interval pairs for 2026–2032. No holiday
names or library implementation are bundled, and no endorsement is implied. The
attribution and license information travel with the integration's source distribution.
Dates outside the table's coverage produce an unknown schedule rather than silently
assuming normal weekday service. This is a website-calendar approximation, not an
official PATH operating calendar or a guarantee of holiday service.
